# ☕ Sunrise Coffee Co.

A responsive, multi-page coffee shop website built using HTML and CSS.

This project was created as part of my project-based learning journey to become a frontend web developer. My goal was to practice building a complete website independently, from writing the HTML structure to styling the pages and publishing the finished project.

## 🌐 Live Website

[View Sunrise Coffee Co.](https://jjotteson2.github.io/sunrise-coffee-co/index.html)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git and GitHub
- GitHub Pages

## ✨ Features

- Responsive navigation for desktop and mobile devices
- Homepage featuring popular coffee drinks
- Menu page with six drinks, descriptions, and prices
- About page explaining the coffee shop's story and mission
- Contact page with business hours and clickable contact links
- Consistent styling across all four pages

## 📄 Website Pages

- **Home:** Introduces Sunrise Coffee Co. and highlights featured drinks.
- **Menu:** Displays six coffee drinks with descriptions and prices.
- **About:** Shares the coffee shop's story, values, and mission.
- **Contact:** Provides fictional business contact information and opening hours.

## 📚 What I Learned

While building this project, I practiced:

- Writing semantic HTML
- Creating navigation between multiple HTML pages
- Styling websites using CSS
- Using Flexbox to position navigation elements
- Using CSS Grid to create a responsive menu layout
- Writing media queries for mobile devices
- Organizing and reusing CSS styles
- Deploying a website using GitHub Pages
